# Eco Platform Frontend

**Eco Platform Frontend** is a React + TypeScript application that interacts with the Eco Platform API.  
This project implements the MVP functionality:

- View list of eco-projects (`/projects`)
- View project details (`/projects/:id`)
- User dashboard (`/dashboard`)
- Login and registration (`/login`)
- Create donations and volunteer applications
- Send messages through the contact form

## Technologies

- React 18 + TypeScript
- Redux Toolkit
- React Router v6
- Axios for API requests
- SCSS/Styled Components (optional)
